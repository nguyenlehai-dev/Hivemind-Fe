# Hivemind-Fe

## Runway scaffold

This repository contains a Vite + React scaffold for the Runway custom workflow interface.

### Run locally

```bash
npm install
npm run dev
```

### Notes

- Set `VITE_API_BASE_URL=http://localhost:8000` if the backend runs on another host.
- The UI expects the FastAPI contract defined in `Hivemind-Be`.
